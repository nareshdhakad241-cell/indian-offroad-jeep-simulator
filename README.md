# Indian Offroad Jeep Simulator

Original offline 4x4 off-road driving game prototype for Android, built with Godot 4.3.

## Current prototype
- Original procedural low-poly jeep and landscape
- Third-person follow camera
- Touchscreen steering, accelerator and brake controls
- Keyboard controls for desktop testing
- Basic ground collision

## Build
GitHub Actions builds a debug APK on every push to `main`. Open the **Actions** tab, select **Build Android APK**, then download the artifact named **Indian-Offroad-Jeep-APK** after a successful run.

## Controls
- Touch: left/right steering, brake and accelerator buttons
- Keyboard: W/up accelerate, S/down reverse, A/D or arrow keys steer
